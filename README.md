# Gerenciador de Tarefas Simples

Este projeto é um **Gerenciador de Tarefas** simples construído com **HTML**, **CSS** e **JavaScript**. Ele permite criar, visualizar, filtrar, concluir e excluir tarefas, com os dados sendo armazenados localmente no navegador usando `localStorage`.

## Funcionalidades

- **Adicionar tarefa**: Adicione novas tarefas com título e categoria.
- **Visualizar tarefas**: Veja a lista de todas as tarefas, com destaque para categorias e status.
- **Filtrar tarefas**: Visualize tarefas pendentes, concluídas ou todas.
- **Marcar como concluída**: Conclua ou desfaça a conclusão de uma tarefa com uma checkbox.
- **Excluir tarefa**: Exclua tarefas da lista.
- **Estatísticas**: Mostra o total de tarefas, tarefas concluídas e o percentual de conclusão.
- **Armazenamento local**: Os dados são salvos no `localStorage`, permitindo que as tarefas persistam mesmo ao recarregar a página.

## Tecnologias Utilizadas

- **HTML5**: Estrutura do layout.
- **CSS3**: Estilização e responsividade.
- **JavaScript (ES6)**: Manipulação do DOM, lógica da aplicação e gerenciamento de eventos.
- **LocalStorage API**: Persistência de dados no navegador.

## Como Usar

1. **Clonar o repositório**:
   ```bash

   ```
2. **Abrir o arquivo HTML**:
   Basta abrir o arquivo `index.html` no navegador para começar a usar o Gerenciador de Tarefas.

## Como Personalizar

- Adicione novas categorias no `<select>` dentro do `<form>` para organizar melhor suas tarefas.
- Atualize os estilos no arquivo `styles.css` para personalizar o visual do gerenciador.
- Adicione imagens, mais estatísticas e novos recursos conforme necessário.
